# MyLoon

个人整理的 [Loon](https://www.nsloon.com/) 插件（`.plugin`）合集，借助 Claude、ChatGPT 辅助编写，但每一条规则都经过实测验证，而不是直接照抄或让 AI 生成后就用——具体做法是抓包对照实际请求命中的规则、目标 IP、连接状态，确认符合预期之后才收进来。

插件文件都放在 [`plugin/`](./plugin) 目录下，涉及的场景大致分两类：

- **IP 属地/风控分流**：只代理真正承载属地判定信号的接口，其余 Feed、图片、视频等媒体 CDN 直连，避免不必要的代理流量和因路由不一致导致的连接异常
- **自定义代理/直连策略**：针对个别 App 单独调整代理行为，比如流量大户为了省代理流量强制直连，或者跳过某些域名的 MITM 以避免认证异常

具体插件以仓库当前实际文件为准，不在这里维护清单，避免更新插件后 README 跟着过时。

## MyLoon Box

仓库附带一个轻量的 Web 插件盒子，入口位于 [`box/`](./box)。

- 自动读取 [`manifest.json`](./manifest.json)
- 搜索、分类筛选插件
- 显示插件名称、版本、描述、图标
- 一键调用 Loon `loon://install?url=...` 安装
- GitHub Actions 会在 `plugin/*.plugin` 发生变化后自动重新生成清单
- 页面本身为纯静态 HTML/CSS/JS，无构建依赖

如果启用 GitHub Pages，可通过：

`https://oliviar13.github.io/MyLoon/box/`

访问盒子页面。

## 使用方法

1. 打开对应 `.plugin` 文件，复制它的 raw 链接（`https://raw.githubusercontent.com/OliviaR13/MyLoon/main/plugin/<文件名>.plugin`）
2. Loon App → 插件 → 右上角 `+` → 粘贴链接 → 添加
3. 如果插件涉及指定代理节点，进入插件配置页手动选一个**固定的单一节点**（`select` 类型策略组，不要用 `url-test`/自动测速类型），避免节点切换打断长连接
4. 确认这些插件在你主配置文件中排在 `GEOIP,cn,DIRECT` 等国内直连规则之前，否则规则可能被提前拦截而失效

## 已知限制

这些插件解决的是**规则/路由层面**的问题，以下几类情况已经过抓包验证是别的原因，**不是插件能修**：

- 部分 App 的接口自带较短的客户端超时，热启动瞬间冷建立到代理节点的连接如果耗时超过这个阈值会被 App 自己取消——本质是节点连接质量/延迟问题，建议换一个延迟更低、连接更稳定的节点，而不是改规则
- CDN 边缘节点偶发的连接被远端重置，属于对端服务器或链路层面的瞬时抖动，规则怎么写都控制不了发生频率
- 如果同时使用了其他会对同一批域名做 MITM 解密/响应体改写的插件（比如去广告类插件），那是独立的另一层机制，出现异常建议分开排查
