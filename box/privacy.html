OliviaR13's隐私政策

最后更新：2026-11-19

这份政策说明 Loon Box 网页（olivia-loon-box.pages.dev）会收集哪些信息、怎么使用、保存在哪里，以及你有哪些选择。插件文件在 Loon 里如何运行，不在本政策范围内。不登录也可以搜索、收藏和安装。

要点

  • 不登录时，收藏和设置只保存在你这台浏览器里，不会上传。
  • 登录（GitHub、Google 或通行密钥）只用于在多台设备之间同步收藏和界面偏好。
  • 本站自己记录的统计只有安装次数，而且不保存 IP 本身。
  • 不出售数据，没有广告，没有访问统计。

1. 我们收集的信息

不登录时，仅保存在你的浏览器里的信息。收藏、排序和界面设置写在当前浏览器的 localStorage 里，不会因为你没登录就上传。包括：

  • 收藏了哪些插件，以及每条收藏的修改时间。
  • 主题、是否显示简介、版本、分类、紧凑列表、置顶收藏、减少动画，以及设置页是否默认全屏。
  • 排序方式。
  • 启动页是否关闭、是否看过新手引导、全屏时单列还是双列。这三项只在本机，登录后也不会同步。
  • 云端同步的开关，以及是否关掉过登录提示。
  • 当天已经上报过安装次数的插件，用来避免同一天重复计数。

搜索词只在当前页面里过滤列表，不会发给服务器。人机验证通过的时间记在 sessionStorage 里，关掉标签页就没有了。

登录时，我们会收到的信息。登录是可选的。

  • GitHub：页面跳到 GitHub 授权，只读取公开用户名和数字 ID。头像由你的浏览器按用户名向 github.com 请求公开头像来显示，不写入 Cookie，也不另存一份图片。
  • Google：授权范围是 openid、email、profile，即账号标识、姓名、头像和已验证的邮箱。头像网址只接受 Google 自己的图片地址（https 的 googleusercontent.com）。
  • 通行密钥：服务器只保存这把密钥的公钥、凭证 ID 和签名计数器，用来核对是不是这台设备。指纹、面容和锁屏密码只留在设备上，不会上传。

GitHub 和 Google 的访问令牌只用于读取上面这些资料，读完即丢，不保存在 Cookie、仓库或日志里。Google 的 ID Token 会用 Google 公布的证书核对签名、签发者、受众和有效期，核对完就丢掉，不保存原文。

使用过程中产生的信息。

  • 安装次数：点「安装」时，如果站点配置了统计（Cloudflare D1），会给这个插件的当天次数加一。保存的是插件 ID、日期和累计次数，记的是点过按钮，不是 Loon 里是否真的装上。页面上的「本周热度」「总安装量」就是这些汇总数字，不含任何个人信息。为了让同一个访客同一天对同一个插件只计一次，服务器会把 IP、插件 ID 和日期加盐做 SHA-256，只保存这个哈希，不保存 IP 本身，也不和登录账号关联。没有配置统计时，不记录。
  • 人机验证：打开插件列表前，首页会加载 Cloudflare Turnstile（challenges.cloudflare.com）做一次验证。服务器把验证令牌和你的 IP 发给 Cloudflare 核对，核对完就丢，不保存。这一页不加载 Turnstile。
  • 浏览器类型：服务器会读取 User-Agent，判断是不是微信内置浏览器（它不能唤起 Loon），是的话只显示一页引导。这个判断不做记录。

2. 我们如何使用这些信息

  • 在你登录后，跨设备同步收藏和已开启同步的界面偏好。
  • 显示你的登录状态，包括名字、邮箱（仅 Google）和头像。
  • 核对人机验证和登录，防止滥用接口。
  • 汇总安装次数，用来显示热度和总安装量。

这些信息不用于广告、画像或其他用途。

3. Cookie 和本地存储

  • 登录 Cookie（mlb_session）：HMAC 签名，带 HttpOnly、Secure、SameSite=Lax，30 天有效。里面是账号 ID、名字（Google 登录时还有已验证的邮箱和头像网址）和过期时间。签名只防篡改，内容没有加密，你在自己的浏览器里能看到，所以不要把这枚 Cookie 发给别人。
  • 验证 Cookie（mlb_verified）：人机验证通过后发放，约 30 分钟有效，只对 /api 生效。已经登录且登录有效时，服务器也接受登录 Cookie 代替验证。
  • 临时 Cookie（mlb_state、mlb_pkce，绑定登录方式时还有 mlb_link）：授权过程中使用，约 10 分钟有效，用完即删。
  • localStorage / sessionStorage：见第 1 节。

4. 一个账号的多种登录方式

GitHub、Google 和通行密钥可以绑在同一个账号上。服务器在已有的 Cloudflare D1（绑定名 MLB_DB；没绑 D1 时用 KV MLB_KV）里记下每种登录方式对应哪个账号：GitHub 的数字 ID 和用户名，Google 的账号标识和已验证邮箱。通行密钥的公钥存在单独的 Cloudflare KV（绑定名 PASSKEYS）；没绑定这个 KV 时，通行密钥登录保持停用，浏览和安装不受影响。

已经在用的账号，ID 保持原来的 GitHub 数字 ID 或 google: 开头的 ID，收藏和设置不会因此换地方。第一次用 Google 登录时，账号 ID 是 google: 加上 Google 的账号标识，免得和 GitHub 的数字 ID 撞车。

如果某种登录方式已经属于另一个账号，不会自动合并。只有你刚完成这次授权，并在页面上确认「注销并绑定」之后，才会删掉那个账号的云端收藏、设置、其他登录方式和通行密钥，再把这次的登录方式转到当前账号。取消，或者超过大约 5 分钟没有确认，就什么都不改。至少要留一种登录方式，不能把最后一种也解绑。

5. 云端同步

登录之后，自动同步默认是开着的，可以在设置里关掉。总开关打开时，收藏会同步；外观（主题、减少动画）、插件卡片（显示项、紧凑模式、收藏置顶、排序）和设置页偏好（默认是否全屏）可以分别关闭，关掉的项目只留在这台设备。启动页开关、全屏单列或双列、新手引导是否看过，不会同步。

同步的数据按账号 ID 存在 Cloudflare D1；没有绑定 D1 时，改存 Cloudflare KV；两者都没配置时，同步不会成功，数据仍只在本机。每个账号最多保存 400 条收藏记录（含已取消的）。多台设备改了同一项时，以较新的那一次为准。取消收藏后，云端会留一条「已取消」记录约 90 天，用来合并各台设备，之后不再保留。

6. 信息的共享和披露

我们不出售你的信息，也不提供给广告或数据分析服务。页面里没有广告脚本，也没有访问统计（没有 Google Analytics、Plausible 这一类）。会联系到的外部服务只有这些：

  • Cloudflare：托管网站、做人机验证，以及在你登录并打开同步之后存放收藏和设置。本站的代码没有额外记录访问日志；作为托管方，Cloudflare 可能按它自己的政策处理常规请求日志，数据也可能在它的全球节点上处理。
  • GitHub 或 Google：只有你点了对应的登录之后才会联系。
  • 头像：已经登录时，浏览器会向 github.com 或 Google 的图片地址请求头像。
  • 插件图标：来自插件清单里填写的图片链接，不是用来追踪访客的。图片所在的服务器能看到你的 IP 和浏览器信息。
  • 安装：点「安装」会唤起 Loon，由 Loon 去 raw.githubusercontent.com 取插件文件。这个请求由 Loon 发出，不经过本站，适用 GitHub 的政策。

字体由本站自己托管，不向第三方字体服务请求。点页面里的外部链接之后，就由对方网站的政策管了。

7. 保留期限

  • 浏览器里的数据：保留到你清除网站数据为止。
  • 登录 Cookie：最长 30 天，或到你退出登录。
  • 云端收藏和设置：保留到账号被注销，或你要求删除。「已取消」记录约 90 天。
  • 安装次数：只有插件 ID、日期和累计次数，作为汇总数据保留。
  • 去重哈希：过了当天的哈希会在之后的安装请求里陆续清理，不是实时删除，所以可能多留几天。

8. 你的选择

  • 退出登录：设置 → 账号 → 退出登录。这会删掉登录 Cookie，这台浏览器里的收藏和设置还在。
  • 关闭同步：在设置 → 云端同步里关掉总开关，或只关掉某一项。
  • 管理登录方式：在设置 → 账号管理里绑定或解绑 GitHub、Google，添加或移除通行密钥。
  • 恢复默认设置：把外观和显示项恢复默认。开着同步时，这些设置会按同步规则写回云端，收藏不会被清掉。
  • 清掉本机数据：在浏览器里清除 olivia-loon-box.pages.dev 的网站数据，localStorage 和 Cookie 会一起去掉。
  • 删除云端数据：站内没有单独的删除按钮，退出登录也不会删掉已经同步的内容。需要删除的话，请开一个 GitHub issue，写明是 GitHub 还是 Google 账号即可。issue 是公开的，请不要贴邮箱以外的敏感信息。

9. 信息安全

登录 Cookie 带 HttpOnly、Secure 和 SameSite 属性，并用服务器密钥签名防篡改。访问令牌、ID Token 和生物特征不会被保存。会改动数据的请求会校验来源是否为本站。不过没有任何网站能保证绝对安全，请自己保管好所用账号和登录 Cookie。

10. 儿童

本站不是专门面向儿童的服务，也不会有意收集儿童的个人信息。

11. 政策变更

这份政策会随功能一起更新。有改动时，页头和文末的「最后更新」日期会跟着变。继续使用本网站，就表示你接受更新后的内容。
