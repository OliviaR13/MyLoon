OliviaR13's隐私政策

最后更新：2026-11-19

本政策说明 Loon Box（以下简称“本服务”）在您使用网页的过程中会处理哪些信息、处理的目的与方式，以及您可以如何管理这些信息。插件在 Loon 客户端内的运行不属于本政策的范围。您无需登录即可浏览、搜索、收藏和安装插件。

要点

  • 未登录时，收藏和设置仅保存在您的浏览器本地，不会上传。
  • 登录仅用于在多台设备之间同步收藏和界面偏好。
  • 本服务自行记录的统计仅限插件安装次数，且不保存您的 IP 地址。
  • 本服务不出售个人信息，不投放广告，不使用访问统计工具。

1. 我们处理的信息

仅保存在您浏览器中的信息。未登录时，下列内容保存在当前浏览器的本地存储中，不会因为您未登录而上传：

  • 收藏的插件及每条收藏的修改时间；
  • 界面设置，包括主题、显示项、列表密度、收藏置顶、动画偏好、排序方式及设置页显示方式；
  • 启动页、新手引导和设置页布局的偏好（这些内容仅保存在本机，登录后也不会同步）；
  • 云端同步开关及登录提示偏好；
  • 用于避免当天重复计数的安装记录。

搜索关键词仅在当前页面内用于筛选列表，不会发送至服务器。人机验证的通过状态仅在当前标签页会话内有效，关闭标签页后即清除。

登录时获取的信息。登录为可选功能。

  • GitHub：读取公开用户名与账号标识。头像由您的浏览器直接向 GitHub 请求公开头像，本服务不另行保存。
  • Google：读取账号标识、姓名、头像及已验证的邮箱地址。头像仅接受来自 Google 的图片地址。
  • 通行密钥：服务器仅保存与该密钥对应的公钥信息，用于验证登录请求。指纹、面容或锁屏密码仅保留在您的设备上，不会上传。

第三方登录所获得的访问凭证仅用于读取上述信息，读取完成后即行丢弃，不予保存。

使用过程中产生的信息。

  • 安装次数：当您点击“安装”时，本服务会对该插件的当日安装次数加一，保存的内容为插件标识、日期和累计次数，不包含任何个人信息。该数字反映按钮被点击的次数，不代表插件已在 Loon 中成功安装。为使同一访客在同一天对同一插件仅计数一次，服务器会对 IP 地址等信息进行单向加密处理，仅保存处理后的结果，该结果无法还原为 IP 地址，也不与您的账号关联。
  • 人机验证：在加载插件列表之前，本服务会使用 Cloudflare 提供的人机验证服务。验证所需的信息（包括 IP 地址）会提交给 Cloudflare 核验，本服务不保存这些信息。
  • 浏览器类型：服务器会识别浏览器类型，以便向无法唤起 Loon 的环境显示说明页面。此项识别不作记录。

2. 信息的使用目的

  • 在您登录后，于多台设备之间同步收藏及已开启同步的界面偏好；
  • 显示您的登录状态，包括名称、头像及邮箱（仅限 Google 登录）；
  • 验证登录与人机验证结果，防止接口被滥用；
  • 汇总安装次数，用于展示插件热度与累计安装量。

上述信息不会用于广告、用户画像或其他目的。

3. Cookie 与本地存储

本服务使用以下类型的 Cookie 与本地存储：

  • 登录凭证：用于保持登录状态，有效期 30 天，采用防篡改签名，并设置了仅限安全传输和禁止脚本读取等安全属性。其内容包括账号标识、显示名称（以及 Google 登录时的已验证邮箱与头像地址）和有效期。该凭证的内容未加密，请勿将其提供给他人。
  • 人机验证凭证：在验证通过后签发，有效期约 30 分钟，仅用于接口访问。登录状态有效时，亦可代替该凭证。
  • 临时授权凭证：仅在登录或绑定登录方式的过程中使用，有效期约 10 分钟，使用后立即删除。
  • 浏览器本地存储：用于保存本政策第 1 节所述的收藏与设置。

4. 账号与登录方式

GitHub、Google 与通行密钥可绑定至同一账号。服务器保存各登录方式与账号之间的对应关系，包括 GitHub 的账号标识与用户名、Google 的账号标识与已验证邮箱，以及通行密钥的公钥信息。绑定后，既有账号的收藏与设置保持不变。

若某一登录方式已属于另一账号，本服务不会自动合并。仅当您完成授权，并在页面上明确确认后，系统才会注销原账号，并永久删除该账号的云端收藏、设置、其他登录方式及通行密钥，随后将该登录方式转移至当前账号。取消，或超过约 5 分钟未确认，则不会作任何更改。账号至少需保留一种登录方式。

5. 云端同步

登录后，自动同步默认开启，您可以在设置中关闭。总开关开启时，收藏将同步；外观、插件卡片和设置页偏好可分别关闭，关闭的项目仅保存在当前设备。启动页、新手引导及设置页布局偏好不会同步。

同步的数据按账号保存在云端存储中。若云端存储不可用，同步将无法完成，数据仍保存在本机。每个账号可保存的收藏记录数量有上限。多台设备对同一项内容作出修改时，以较新的修改为准。取消收藏后，云端会保留一条“已取消”记录约 90 天，用于多台设备之间的合并，期满后不再保留。

6. 信息的共享与披露

本服务不出售您的信息，也不向广告或数据分析服务提供您的信息。页面中不含广告脚本，也不使用访问统计工具。本服务会联系的外部服务仅包括：

  • Cloudflare：提供网站托管、人机验证服务，并在您登录且开启同步后存储您的收藏与设置。作为托管服务提供者，Cloudflare 可能依据其自身政策处理常规请求日志，相关数据也可能在其全球节点上处理。
  • GitHub、Google：仅在您选择相应登录方式时联系。
  • 头像：登录后，您的浏览器会向 GitHub 或 Google 的图片地址请求头像。
  • 插件图标：来自插件清单中指定的图片地址，图片所在服务器可以获知您的 IP 地址和浏览器信息。
  • 插件安装：点击“安装”后由 Loon 从 GitHub 获取插件文件，该请求由 Loon 发出，不经过本服务，适用 GitHub 的相关政策。

页面使用的字体由本服务自行托管。您点击页面中的外部链接后，相应网站的隐私政策将适用。

7. 保留期限

  • 浏览器本地数据：保留至您清除网站数据；
  • 登录凭证：最长 30 天，或至您退出登录；
  • 云端收藏与设置：保留至账号被注销，或应您的要求删除；“已取消”记录约 90 天；
  • 安装次数：以汇总形式保留，仅含插件标识、日期和累计次数；
  • 用于当日去重的加密结果：过期后会在后续请求中陆续清理，实际保留时间可能略长于一天。

8. 您的选择

  • 退出登录：在“设置 → 账号”中退出。登录凭证将被删除，本机的收藏与设置仍然保留。
  • 关闭同步：在“设置 → 云端同步”中关闭总开关或单项开关。
  • 管理登录方式：在“设置 → 账号管理”中绑定或解绑 GitHub、Google，添加或移除通行密钥。
  • 恢复默认设置：将外观与显示项恢复为默认值。已开启同步时，该设置会按同步规则写入云端，收藏不受影响。
  • 清除本机数据：在浏览器中清除本站的网站数据，即可删除本机保存的全部内容。
  • 删除云端数据：目前站内未提供单独的删除入口，退出登录也不会删除已同步的内容。如需删除，请通过 GitHub Issues 提出请求，并说明所用登录方式。Issues 为公开页面，请勿在其中提供邮箱以外的敏感信息。

9. 信息安全

本服务对登录凭证采取防篡改签名及安全传输等保护措施，不保存第三方登录的访问凭证和生物特征信息，并对修改数据的请求校验来源。但任何网络服务均无法保证绝对安全，请妥善保管您的账号和登录凭证。

10. 未成年人

本服务并非专门面向儿童，也不会有意收集儿童的个人信息。

11. 政策的变更

本政策可能随功能调整而更新。更新后，页首与文末的“最后更新”日期将随之变更。您在更新后继续使用本服务，即表示接受更新后的政策。

12. 联系我们

如有疑问或需提出删除请求，请通过 GitHub Issues 与我们联系。使用规则请参阅 使用条款。
